REST Client

1. Define a JAX-RS service interface:

    @Path("/posts")\n
    public interface PostService {\n
    \n
        @GET\n
        @Path("/{id}")\n
        @Produces(MediaType.APPLICATION_JSON)\n
        Post getPost(@PathParam("id") long id);\n
    \n
        @GET\n
        @Produces(MediaType.APPLICATION_JSON)\n
        List<Post> listPosts();\n
    }\n

2. Configure the REST endpoint with a @Produces method:

    @ApplicationScoped\n
    public class RestDemoConfig {\n
    \n
        @Produces\n
        @Named("jsonplaceholder")\n
        public RestConfig jsonPlaceholderRestConfig() {\n
            return RestConfig.builder()\n
                .baseUrl("https://jsonplaceholder.typicode.com")\n
                .build();\n
        }\n
    }\n

3. Inject the Caller with the matching @Named qualifier:

    @Inject\n
    @Named("jsonplaceholder")\n
    Caller<PostService> postServiceCaller;\n
    \n
    postServiceCaller\n
        .call(response -> {\n
            Post post = (Post) response;\n
        })\n
        .getPost(1);\n
